# AX Process Innovation 자기주도 학습 앱 설계

## 목표

기존 강의용 reveal.js 슬라이드와 별도로 `/study/`에서 개인이 혼자 학습할 수 있는 5일 과정 학습 앱을 제공한다. 강의 자료를 단순 분할하지 않고, 설명이 이어지는 읽기 중심 교재로 재구성한다.

## 학습 방식

- 일정: 5일, 하루 45~70분
- 중심 활동: 개념 읽기와 이해도 퀴즈
- 선택 활동: 각 Day의 `더 해보기` 실습
- 학습 흐름: 학습 목표 → 본문 → 핵심 도표 → 사례 → 퀴즈 → 요약

## 정보 구조

1. Day 1 — AX와 Process Innovation의 기본 개념
2. Day 2 — E2E 관점과 As-Is 진단
3. Day 3 — ECRS와 인간-AI 역할 재설계
4. Day 4 — 우선순위, ROI, 비즈니스 케이스
5. Day 5 — 파일럿, 거버넌스, 변화관리

각 Day는 여러 개의 짧은 레슨과 3~5문항 퀴즈로 구성한다. 메인 대시보드는 전체 진도, 일자별 완료 상태, 마지막 학습 위치와 이어보기 동작을 제공한다.

## 기술 구조

- GitHub Pages에서 동작하는 정적 단일 페이지 앱
- `study/index.html`, `study/styles.css`, `study/app.js`, `study/content.js`로 분리
- 별도 빌드, 서버, 로그인 없음
- `localStorage`에 완료 레슨, 마지막 위치, 퀴즈 점수 저장
- 저장 데이터가 없거나 손상되었을 때 안전하게 초기 상태로 복구
- 기존 `index.html`에 개인 학습 진입 버튼 추가

## 주요 화면과 동작

- 학습 홈: 5일 코스 지도, 전체 진도율, 이어서 학습
- 레슨 뷰: 읽기 콘텐츠, 이전/다음 이동, 현재 위치 표시
- 퀴즈: 답 제출 후 정답과 해설 표시, Day별 최고 점수 저장
- 완료 처리: 모든 필수 레슨을 읽고 퀴즈를 제출하면 Day 완료
- 더 해보기: 기본적으로 접혀 있으며 학습 완료 조건에는 포함하지 않음
- 진도 초기화: 확인 절차 후 브라우저 저장 데이터 삭제

## 시각 및 접근성

- 기존 AX 사이트의 짙은 남색, 보라·파랑·시안 그라데이션을 계승
- 장문 독해를 위해 본문 폭과 줄 길이를 제한하고 밝은 카드 대비 사용
- PC와 모바일 반응형
- 의미 있는 제목 구조, 키보드 포커스, 버튼 상태, 진행률 레이블 제공

## 검증

- 테스트 우선으로 상태 계산, 저장·복구, 퀴즈 채점 동작 검증
- 브라우저에서 첫 진입, 레슨 이동, 퀴즈 제출, 새로고침 후 진도 복원, 초기화 흐름 확인
- 데스크톱과 모바일 화면을 캡처해 겹침, 잘림, 가독성을 점검
- 배포 후 `/axpi/study/`와 주요 정적 자원의 HTTP 200 확인
